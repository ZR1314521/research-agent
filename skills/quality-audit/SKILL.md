# Quality Audit

Use this skill when the user asks why results are missing, how many requests were made, which source failed, why the workflow stopped, or where the logs are.

Required output:

- source request counts
- source failures and error messages
- included, excluded, and edge paper counts
- stop condition
- relevant artifact paths
- clear next action when the run can be continued
