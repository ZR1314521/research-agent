# Academic Search Multisource

Parse topic, dates, venues, sources, and result limit. Query selected public sources, preserve raw metadata, deduplicate by DOI or normalized title, and pass candidates to screening. Use bounded recursive retrieval only when requested or when the target pool is not reached.
