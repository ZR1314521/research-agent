# 科研智能体本地平台增强设计

日期：2026-07-14
状态：已确认，待实施

## 1. 目标与范围

在现有 React 工作台和 FastAPI 本地后端上做渐进式增强，不迁移框架，不改写 Agent 核心。交付目标包括：首页品牌与动效升级、顺滑页面切换、真实用量统计、可管理的学术数据源、色彩设计、权限与隐私、仅本机账号信息，以及后端存活期间可执行的定时任务。

本轮保持单用户、本地优先。外部账号系统、跨设备同步和任意付费网站的自动登录适配不在本轮实现。

## 2. 方案选择

采用“React 前端 + FastAPI 单进程本地服务 + SQLite 持久化”的一体化方案。

- 不采用纯前端模拟，因为数据源、统计和调度必须形成真实闭环。
- 不拆分独立任务服务，因为当前是单机产品，额外进程会提高启动和维护成本。
- 新功能通过边界清晰的服务和 API 接入现有 Agent，不把调度、统计或数据源逻辑塞回聊天组件。

## 3. 首页与全局交互

### 3.1 品牌与入口

- 在首页主标题“面向科研人员的本地智能工作台”上方展示用户提供的中国联通与元景 MaaS 双 Logo 组合图。
- Logo 保持原始标识，不重新绘制或改变商标比例。
- 主操作区使用左侧 `Join Us`、右侧 `Chat` 的双入口结构。
- `Join Us` 以新窗口打开 `https://maas.ai-yuanjing.com/`；`Chat` 进入科研工作台。

### 3.2 功能卡交互

- 功能卡响应鼠标位置产生轻微 3D 倾斜、阴影位移和高光变化。
- 指针离开时使用自然回弹，不出现持续摇晃或大角度旋转。
- 动效只使用 `transform`、`opacity` 和 CSS 自定义属性，避免布局抖动。
- 触屏设备禁用指针倾斜；系统启用 `prefers-reduced-motion` 时关闭非必要动画。

### 3.3 页面切换

- 页面切换使用约 220 毫秒的淡入、轻位移和轻微模糊消退。
- 顶部导航保持稳定，不随页面内容重新挂载或跳动。
- 动画期间不阻断点击，不清理正在运行的 Agent 会话。

## 4. 科研工作台与审批

- 保留现有会话、上传、流式消息、暂停、恢复、格式转换和任务状态逻辑。
- 保留现有 `waiting_approval` 状态以及 `/runs/{run_id}/approve`、`/runs/{run_id}/reject` 接口。
- Agent 请求敏感操作时显示“允许 / 拒绝”确认卡；允许后继续原流程，拒绝后终止当前待审批动作。
- 切换到其他页面时审批状态和运行状态继续保存在后端，返回工作台后恢复显示。

## 5. 设置页信息架构

设置页固定为六个栏目：

1. 快速设置
2. 用量统计
3. 学术数据源
4. 色彩设计
5. 权限与隐私
6. 账号信息

### 5.1 快速设置

继续复用现有模型提供商、API Key、Base URL、模型名称、上下文长度、超时和并发设置逻辑。保存后明确提示需要重启后端才能让新模型配置生效。

### 5.2 用量统计

后端聚合所有会话的 `provider_calls.jsonl`，输出真实请求记录和统计结果。统计计算由本地代码完成，不调用模型。

页面包含：

- 总 Token、请求数、输入 Token、输出 Token、总耗时、成功率；
- 按时间聚合的使用趋势；
- 请求日志、Provider 统计和模型统计三个视图；
- 按 Provider、模型、状态和日期筛选；
- 费用字段仅在存在明确价格配置时计算，否则显示“未定价”，不生成推测费用。

图表采用轻量 SVG/CSS 绘制，延续奶油色主题，不引入新的图表依赖。

### 5.3 学术数据源

内置并展示当前已有的四个可编程来源：OpenAlex、Semantic Scholar、PubMed、arXiv。每个来源显示启用状态、访问方式、最近检测时间和连接结果。

新增数据源分为：

- 免费来源：填写名称和网站 URL。系统将其注册为限定域名的网页检索来源，可供现有网页搜索/抓取能力使用；仅填写网址不等同于自动获得该网站私有 API。
- 付费来源：填写名称、登录地址或 API 地址、账号和密码。凭据只保存在本机，使用 Windows DPAPI 加密，接口和页面只返回脱敏值。

本轮实现新增、编辑、删除、启用、停用、连接检测和本机加密持久化。任意付费网站的浏览器自动登录或专属 API 适配留给后续连接器阶段。

### 5.4 色彩设计

- 提供多套舒适的奶油风预设色板。
- 支持调整页面背景、卡片背景、强调色、主要文字、次要文字和边框色。
- 修改后即时预览；配置保存在浏览器本地并在刷新后恢复。
- 提供“恢复默认”操作，并保证对比度满足基本可读性要求。

### 5.5 权限与隐私

- 展示和控制外部网络访问、敏感操作审批、日志保留期限和凭据脱敏状态。
- 保持敏感操作默认需要人工确认，不提供默认自动批准。
- 提供审批记录查看、本地运行记录清理和数据源凭据删除。
- 清理操作必须二次确认；账号密码永不通过普通查询接口返回明文。

### 5.6 账号信息

支持本地头像、显示名称、单位、邮箱、职称和简介。信息仅用于本机界面展示，暂不实现注册、登录、云同步或外部服务器校验。

## 6. 定时任务

### 6.1 创建与执行

定时任务包含名称、完整 Agent 指令、计划类型、执行时间、时区和启用状态。首版支持一次性、每天和每周三种计划。

后端调度器在 FastAPI 生命周期内运行：

1. 周期性查询到期任务；
2. 原子认领任务，防止同一任务重复执行；
3. 创建新的 Agent 会话；
4. 将保存的完整指令作为用户消息交给现有执行链；
5. 保存生成的会话 ID、运行状态、开始/结束时间和下一次执行时间。

浏览器可以关闭，但后端必须保持运行。后端关闭期间错过的计划标记为“已错过”，不自动补跑；用户可在任务中心点击“立即运行”。

### 6.2 人工干预

- 定时任务触发审批时，会话进入“待确认”，任务中心同步展示。
- 用户从任务中心打开对应会话后使用现有允许/拒绝按钮处理。
- 支持暂停计划、恢复计划、立即运行和删除计划。

## 7. 后端边界与数据模型

新增三个独立服务：

- `UsageService`：只读聚合 Provider 调用日志并生成统计结果；
- `DataSourceRegistry`：管理内置来源、自定义来源和加密凭据；
- `ScheduleService`：管理计划、到期认领和执行记录。

SQLite 增加数据源、设置、计划任务和计划执行记录。现有会话表和 Agent 运行目录保持兼容。

新增 API 按 `/usage`、`/data-sources`、`/settings`、`/schedules` 分组。错误响应返回可显示的中文说明，前端使用内联错误状态，不使用浏览器弹窗。

## 8. 安全与错误处理

- 付费凭据使用 Windows 用户级 DPAPI 加密；数据库不保存明文。
- 后端日志不得打印密码、API Key 或解密后的凭据。
- URL 只允许 `http`/`https`，并限制长度；连接检测设置短超时。
- 调度任务失败不会使调度线程退出，失败记录包含脱敏错误摘要。
- 不可达数据源保留配置并标记失败，用户可重新检测。
- 用量日志中的损坏行被跳过并计入诊断计数，不影响其他统计。

## 9. 验证标准

- 首页双 Logo、Join Us、Chat、功能卡倾斜和页面过渡均可操作，键盘焦点清晰，减少动态效果设置有效。
- 现有审批、暂停/恢复、上传和对话流回归测试通过。
- 四个内置学术源显示正确；免费和付费来源可完整增删改查；付费密码不以明文落盘或返回。
- 用量统计与真实 Provider 日志样本计算结果一致，未定价模型不显示虚假费用。
- 一次性、每天和每周任务可创建、暂停、恢复、立即执行；到点只触发一次。
- 后端重启后计划仍存在；错过任务按约定标记，不自动补跑。
- React 生产构建成功，Python 完整测试通过，并完成本地启动烟雾测试。

## 10. 明确不做

- 外部用户注册、登录、云端账号同步；
- 跨设备计划任务；
- 后端关闭期间继续调度；
- 对任意付费网站自动生成登录适配器；
- 缺少价格依据时估算模型费用；
- 更换 React、FastAPI 或现有 Agent 核心架构。
