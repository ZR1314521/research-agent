# Research Agent 四页面前端改版设计

日期：2026-07-14

## 目标

把现有单页科研 Agent 工作台改造成面向普通科研用户的四页面本地 Web 应用：

- 首页
- 科研工作台
- 任务中心
- 设置

四个页面使用统一的奶油风视觉系统。现有 Agent、会话、流式事件、文件上传、暂停/恢复、审批、格式处理和模型配置逻辑继续使用；本次不重写后端能力。

## 本次范围

### 首页

首页只承担产品介绍，不展示最近任务、最近成果、用量、运行状态或快捷任务卡。

页面结构：

1. 顶部统一导航栏。
2. Hero 区：产品定位、简短说明和科研主题插画式视觉区域。
3. 主操作按钮 `Chat`，点击后进入科研工作台。
4. 六个能力介绍模块：
   - 文献检索与筛选
   - 文献阅读与综述
   - 实验数据分析
   - 科研图表生成
   - 参考文献管理
   - 文档写作与编辑
5. 简洁页脚。

### 科研工作台

工作台保留当前全部真实逻辑，只重构页面结构、样式和用户文案。

左侧会话栏：

- `新建会话` 大按钮。
- `删除会话` 大按钮。
- 历史会话列表、当前会话高亮、日期与标题截断。
- 继续使用现有会话创建、切换和删除逻辑。

右侧工作区：

- 当前会话标题和运行状态。
- 暂停、恢复、取消控制。
- 用户与 Agent 对话。
- 工具步骤、模型调用状态、审批卡片和成果文件。
- 底部固定输入区。
- 工具栏保留上传文件、计划模式、删除消息等功能。
- 当前 `引用格式` 入口改名为 `格式转换`，但继续复用现有格式列表和执行逻辑。
- Accept/Reject 只在需要审批时显示为上下文操作，不长期占用输入区。
- 模型名和 Token 使用量以轻量信息显示，不做仪表盘。

### 任务中心

本阶段以完成样式和基本数据呈现为主，不实现调度器、后台任务队列或真正的预约执行。

页面结构：

- `全部任务` 和 `定时任务` 两个页签。
- `新建定时任务` 按钮只提供样式和明确的未开放提示。
- 状态筛选：全部、运行中、待确认、已暂停、失败、已完成。
- 主区域采用横向任务列表，展示任务名、状态、当前进度、更新时间、成果和操作。
- 优先使用现有 `/sessions` 返回的真实会话数据填充任务行；没有数据时显示空状态，不伪造运行结果。
- `打开` 可跳转科研工作台并选中对应会话。
- 暂停、恢复、重试、定时执行等复杂控制本阶段只做禁用态或后续能力提示，不新增后端接口。
- 右侧可显示简洁的今日任务和下一次定时任务样式区域，但不展示虚假统计。

### 设置

设置页采用左侧分类导航、右侧内容区。

左侧分类：

- 快速设置
- 模型服务
- 学术数据源
- 科研偏好
- 权限与隐私
- 系统与诊断

`快速设置` 为本阶段唯一完整接线的设置模块：

- 继续调用现有 `/setup/presets` 获取服务商预设。
- 继续调用现有 `/setup/apply` 保存模型配置。
- 保留 Provider、API Key、Base URL、模型名称、上下文长度、超时和并发数。
- 上下文长度、超时和并发数放入折叠的高级选项。
- 增加服务商官方网站、API Key 申请地址和官方文档链接；链接来自前端预设映射，不包含密钥。
- `测试连接` 复用现有健康或模型测试能力；若当前后端没有独立测试接口，则清楚提示需要保存并重启，不伪造连接成功。
- `保存并应用` 保留现有保存行为和重启提示。

其余设置分类本阶段只实现统一样式、栏目说明和空状态，不保存伪配置。

## 导航与页面状态

顶部导航在四个页面保持一致，当前页面使用柔和鼠尾草绿色胶囊高亮。

本次不新增路由依赖。前端使用轻量页面状态和 URL hash 同步：

- `#/home`
- `#/workspace`
- `#/tasks`
- `#/settings`

刷新页面后根据 hash 恢复当前页面。首页 `Chat` 按钮进入 `#/workspace`；任务中心 `打开` 操作进入工作台并加载对应会话。

## 组件边界

避免继续扩大当前单体 `App.js`。前端拆分为边界清楚的组件：

- `AppShell`：顶部导航与页面切换。
- `HomePage`：纯介绍页面。
- `WorkspacePage`：承接现有工作台状态与接口逻辑。
- `TaskCenterPage`：会话列表式任务视图。
- `SettingsPage`：设置分类与快速设置。
- `ConversationSidebar`：会话创建、删除和切换。
- `ChatTimeline`：消息、步骤、模型调用与成果。
- `ChatComposer`：上传、格式转换、计划模式、删除消息和发送。
- `QuickSetupPanel`：现有模型配置逻辑。

共享的数据请求仍在页面或专用 hooks 中完成，不把 Agent 语义判断写进前端组件。

## 视觉规范

- 背景：暖象牙白与浅奶油色。
- 主色：低饱和鼠尾草绿。
- 辅色：燕麦米色、浅桃色、可可灰。
- 文本：暖深灰，不使用纯黑大面积压迫页面。
- 圆角：导航和主容器为中等圆角，避免每个小元素都胶囊化。
- 阴影：低对比柔和阴影。
- 图标：统一细线图标，不使用机器人形象。
- 避免蓝紫 AI 模板、霓虹、玻璃拟态、深色侧边栏和密集仪表盘。
- 桌面端优先；窄屏时导航允许横向滚动或紧凑显示，会话栏折叠为抽屉。

## 数据流与兼容性

- 首页为纯前端展示，不产生后端写入。
- 工作台继续使用当前 runs、turn stream、upload、pause、resume、cancel、approve、reject、trim 和 setup 接口。
- 任务中心只读取现有 sessions 数据，不创建新的任务状态来源。
- 设置快速配置继续写入现有项目配置，不改变密钥字段和后端加载方式。
- 页面切换不能终止正在运行的 Agent turn；任务状态仍以现有后端为准。
- 工作台和任务中心展示同一个 run/session 状态，不复制状态。

## 错误与空状态

- 后端不可用：在当前页面显示简短错误，不清空用户输入和已有界面状态。
- 无历史会话：显示空状态和新建会话入口。
- 无任务：任务中心显示空任务说明，不展示示例假数据。
- 设置保存失败：保留表单内容并显示后端错误。
- 未实现栏目：明确标记“后续开放”，按钮不产生假成功反馈。
- 运行中的页面切换和流式重连继续遵循现有 generation/turn ID 防串线机制。

## 非目标

本阶段不包含：

- 新任务调度后端。
- 真正的预约、每天、每周或每月执行。
- 新的数据库表或 API。
- 后端 Agent、工具注册表、会话存储或科研能力重构。
- 任务中心复杂统计和用量报表。
- 设置页其他分类的真实保存逻辑。
- 新增前端 UI 框架或路由依赖。

## 验收标准

1. 四个顶部导航项均可切换并在刷新后保持页面。
2. 首页符合参考图布局，且 Chat 按钮进入科研工作台。
3. 工作台现有关键操作继续可用：会话、新建/删除、消息、上传、流式步骤、暂停/恢复/取消、计划、审批、删除消息、格式转换和成果展示。
4. `引用格式` 用户文案已改为 `格式转换`，后端行为不变。
5. 任务中心呈现真实会话列表或可信空状态，并可打开会话。
6. 设置快速配置可加载预设、填写并保存；其他栏目有完整视觉占位。
7. 四个页面视觉一致，无深色侧边栏和蓝紫模板风。
8. `npm run build` 成功。
9. 现有 Python 后端回归测试继续通过。
